### CALDtalk Next
**Multilingual communication application**

A Vue 3 and TypeScript rebuild of the original CALDtalk concept, focused on responsive multilingual workflows, curated phrases, searchable translation history, browser-based speech output, and accessible desktop/mobile experiences.

The current release is a frontend MVP, with the architecture prepared for future translation API, authentication, and backend integration.

**Tech:** Vue 3, TypeScript, Pinia, Vue Router, Vite

- Repository: https://github.com/UNSWRuilinZhao/caldtalk-next
